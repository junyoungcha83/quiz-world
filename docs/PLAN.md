# 퀴즈세상 — 최종 계획서

승호·승아가 분야와 단계를 골라 푸는 퀴즈 PWA. 게임월드의 '퀴즈' 아이콘으로 열고, 따로 설치도 된다.

## 1. 구성

| 섹션 | id | 형태 | 점수 |
|---|---|---|---|
| 역사 | `history` | 4지선다 | O |
| 일반상식 | `general` | 4지선다 | O |
| 시사 | `news` | 4지선다 | O |
| 넌센스 | `nonsense` | 답보기 | X (그냥 즐기기) |
| 영어단어 | `english` | 4지선다 | O |

## 2. 대상과 단계

- 사용자: 게임월드의 사용자(승호·승아)를 그대로 쓴다. 게임월드 서버에서 사용자 목록을 읽어 오고, 기록은 게임월드 사용자 id 로 저장한다.
- 단계: 섹션마다 1~4단계. **아이가 직접 고른다**(자동 승급 없음).

| 단계 | 수준 | 기준 |
|---|---|---|
| 1 | 유치원 | 그림책·일상 경험으로 알 수 있는 것 |
| 2 | 초등 저학년(1~2) | 교과서 1~2학년 범위 |
| 3 | 초등 고학년(3~6) | 교과서 3~6학년 범위(사회·과학 포함) |
| 4 | 중학교 | 중학 교과 범위 |

- 문제가 없는 칸(예: 시사 1단계)은 앱에서 숨긴다.

## 3. 문제 만들기

- 만드는 곳: **맥의 Claude Code 세션**(API 과금 없음). 앱은 AI를 부르지 않는다.
- 흐름: 초안 생성 → 사실 확인(출처 기록) → 기계 점검 → 사람 훑어보기 → `verified` 만 앱 데이터에 등록.
- 4지선다: 문제 · 선택지 4개 · 정답 · 짧은 해설. 넌센스: 문제 · 답 · (선택) 한 줄 풀이.
- 참고 자료 문장을 그대로 옮기지 않는다. 사실을 확인한 뒤 새로 쓴다.

### 출처

| 섹션 | 출처 | 규칙 |
|---|---|---|
| 역사·상식 | 공공기관·교과 자료, 신뢰할 수 있는 참고자료 | 주소+확인 날짜 필수 |
| 시사 | 정부·기관 공식 발표, 언론 보도 | 주소+확인 날짜+**기준 날짜+유효기한** 필수 |
| 영어단어 | 교육부 기본 어휘 목록(승호의사전 `level.json`) + 사전 뜻·예문 | 단어 목록 출처 자동 기록 |
| 넌센스 | **직접 창작만** | 출처 = `자체 창작` (주소 없음 허용) |

출처가 없으면 등록하지 않는다(넌센스 제외).

### 기계 점검 (`tools/validate.mjs`)

- 필수 항목 누락, 단계·섹션 값 오류
- 4지선다: 선택지 정확히 4개, 서로 다름, 정답 번호 유효
- "모두 정답/정답 없음/위의 것 모두" 같은 선택지 금지
- 정답만 유난히 긴 선택지 경고(다른 선택지 평균의 1.8배 이상)
- 같은 문제·비슷한 문제(글자 유사도) 중복 검출 — 섹션 전체 기준
- 시사: 기준 날짜·유효기한 필수, 이미 지난 유효기한 경고
- 출처 주소·확인 날짜 형식

### 사람 확인 + 신고

- 섹션마다 일부를 직접 훑어본다.
- 앱의 **"문제가 이상해요"** 버튼 → 서버에 신고 기록 → 그 문제는 **두 아이 모두에게 숨김**.
- 맥에서 신고 목록을 보고 **고치거나 되살린다**(잘못 누른 신고 복구).

## 4. 시사 운영

- 업데이트는 맥에서 필요할 때(비정기).
- 문제마다 **기준 날짜·유효기한**(기본 3개월). 기한이 지나면 앱이 자동으로 숨긴다 — 업데이트가 늦어도 틀린 정답이 나오지 않게.
- 정치적으로 논쟁이 되는 주제, 사건·사고 위주의 자극적 소재는 다루지 않는다.

## 5. 앱 기능

- 사용자 선택 → 섹션 → 단계 → 10문제 한 판.
- 4지선다: 고르면 **바로 정답·해설**. 선택지 순서는 **풀 때마다 섞는다**.
- 넌센스: 문제 → "답 보기" → 다음. 점수·오답 노트 없음, 즐겨찾기만.
- 점수·연속 정답(최고 기록), 오답 노트, 즐겨찾기 — **아이마다 따로**.
- 오답 노트: 틀린 문제가 들어가고, **다시 풀어 2번 연속 맞히면 빠진다**.
- 문제 배분(가중치): 안 푼 문제 우선 → 최근에 틀린 문제 → 맞힌 문제는 맞힌 횟수·최근일수록 덜 나옴.
- 폰·맥 어디서든 이어서: Cloudflare Worker + KV 동기화.

## 6. 동기화 원칙 (가계부 사고 재발 방지)

- 사용자별로 저장을 나눈다(`progress:<userId>`). 한 아이 저장이 다른 아이를 덮지 않는다.
- 서버는 받은 기록을 **덮어쓰지 않고 병합**한다(문제별 카운터는 큰 값, 최근 시각은 늦은 값, 즐겨찾기는 시각 비교).
- 신고는 별도 키로 **추가만** 한다.

## 7. 데이터와 앱의 분리

- 문제는 `data/q/<섹션>-<단계>.json` 파일로 따로 둔다. 문제 추가·수정은 파일 교체만 — 앱 코드 재배포 없음.
- `data/index.json` 에 섹션·단계별 파일과 문제 수, 데이터 버전을 적는다. 앱은 이 버전으로 새 문제를 알아챈다.
- 초안은 `tools/drafts/` 에서 만들고, 점검을 통과한 것만 `data/q/` 로 옮긴다.

## 8. 개발 순서

1. 데이터 구조 + 기계 점검 도구 ✅
2. 시범: 역사 2단계 30문제 + 넌센스 10문제 생성·검증 ✅
3. 앱 뼈대: 사용자 선택(게임월드 연동) → 섹션·단계 → 풀이 → 즉시 해설 → 점수 ✅
4. 오답 노트·즐겨찾기·배분 가중치·신고 ✅
5. 동기화 Worker + PNG 아이콘·설치 → GitHub Pages 배포 ✅
6. 게임월드에 '퀴즈' 아이콘 추가
7. 섹션·단계별 문제 확충(수량은 만들면서 정함), 시사 첫 업데이트

## 9. 관리자 모드 (2026-10-18 추가)

- 앱 홈 맨 아래 **⚙️ 관리자** → 관리자 비밀번호(아이 폰의 동기화 비밀번호와 별개) → 직접 문제 만들기.
- 입력: 기본(4지선다)/넌센스 선택 → 분야·단계 → 문제 → 보기 4개+정답(넌센스는 답 1개) → 유효기간(시사만) → 해설·출처(선택).
- **검증 과정 없이** 저장 즉시 두 아이에게 보인다. 서버 KV `custom` 에 저장(앱 코드·문제 파일 재배포 없음).
- 만든 문제는 같은 화면에서 고치기·지우기. 신고·오답 노트·즐겨찾기도 기본 문제와 똑같이 동작.
